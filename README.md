# Restaurant Billing System

A desktop-based restaurant billing application developed using Java Swing
and NetBeans.

## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- NetBeans

## Features

- Menu item selection
- Quantity management
- Automatic subtotal calculation
- 5% GST calculation
- Grand total calculation
- Receipt generation
- MySQL database integration using JDBC
- Transaction record storage

## How to Run

1. Clone the repository.
2. Open the project in NetBeans.
3. Configure the MySQL database.
4. Update the database connection credentials.
5. Run the application.

## Database Configuration
Set the `DB_password` environment variable to your local MySQL root password before running the application.
